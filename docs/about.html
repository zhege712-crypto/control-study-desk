本地 PDF 如何处理

点击“选择本地 PDF”后，文件通过浏览器 File API 与本地加载的 PDF.js 解析，仅在当前页面内存中使用。网站没有文件上传接口，不把 PDF、文件名或 PDF 正文写入 localStorage、GitHub 仓库或服务器。文件选择及页面内文件名仅用于当前页面显示，刷新或关闭页面后需要重新选择；也可点击“清除所选文件”主动清除。浏览器自身缓存、内存管理及扩展行为由你的浏览器控制。

所选 PDF 不会自动进行身份认证，请自己核对标题、作者、版本和文件页序。选择文件不会授予本网站复制或公开传播该论文的权利。

阅读记录与访问数据

本应用没有账号、广告、第三方统计脚本、远程字体或运行时 CDN。代码与依赖由站点同源加载。搜索在当前页面执行，不提交给站点；可分享链接只包含区块、论文标识和页码，不包含搜索词、文件名或本机路径。

浏览器 localStorage 的 paper-study-desk-v1 项保存最近的知识区块、分类、历史章节、论文标识和页码；不会跨设备同步。清除此站点的数据即可删除。关闭页面后，阅读位置仍可能保留在当前浏览器中。

GitHub Pages 作为托管方会接收页面资源请求，可能处理 IP、请求时间、浏览器信息等访问数据；本项目不能代替托管方承诺“完全不记录”。另见 GitHub 隐私声明。点击 DOI、Crossref 或其他外部链接后，对方网站按其隐私政策处理访问。链接使用 no-referrer 策略；本项目没有嵌入第三方阅读器。

公开范围与更正

此仓库和网页公开，教学文字及书目信息可能被搜索引擎索引、克隆或缓存。发布包采用文件白名单，不包含论文副本、私人研究交接、绝对磁盘路径、实验记录、凭据或本机截图。如发现来源、版权或内容问题，可通过仓库 Issue 联系维护者；Issue 是公开的，请勿提交论文全文、私人信息或访问凭据。更正或移除站点内容不能保证删除第三方已有的副本。

# 论文学习台 / Control Study Desk

中文解释、英文术语与文献出处相连的静态学习网站。50 个独立知识区块，包含 CBF、CLF、QP、MPC、PE、Hankel、Laplacian、Zeno/MIET 等概念。

在线阅读：https://zhege712-crypto.github.io/control-study-desk/

## 发展历程与知识关联

控制史长文按时代连续叙述，三篇手算样章展开反馈、时延与多智能体。知识关系图含五种关系、16 条带说明的有向连线；十五篇补充文献标明 DOI、版本与实际阅读范围，并提供 BibTeX 下载。可切换增益与一拍延迟，核对解析根、曲线和逐步记录。新增 PDF 不进入公开仓库。

## 从基础到研究行动

新增基础三问（运动、程序更新、反馈）与八个研究实践区块。研究起步页提供六阶段行动单，可分别编辑、复制和下载本轮疑问、动作、证据、停止条件与结果；草稿仅在页面内存，刷新清空。下载的 research_starter.py 提供可核对的标准库教学练习；不执行真实科研任务。

## 深入讲解

26 个区块新增 64 节教学展开，补充符号解释、逐步推导、完整手算、反例、适用条件和自测。涵盖一致性与通信、CBF/CLF/CBF-QP、MPC 与递归可行性、Hankel/PE，以及读论文、复现和公平比较。新增例子是解析教学构造；论文依据和选读页码仍单独标注。

## 初学者入口

首页提供可跳转的入门路线；交互区包含一致性、队形、通信与安全过滤四个教学例子，支持调整条件、逐步播放、查看数值与公式、自测和下载 Python 代码。研究起步页提供可填写、预览、复制和下载的研究问题卡；草稿只在当前页面内存中保留，不上传，刷新会清空。

## 论文来源、版权和隐私

完整说明及五篇参考文献的作者、刊物、正式年份、DOI、选读版本和页码见 [来源与隐私说明](docs/about.html)。本仓库不分发论文 PDF 或原始图表，不包含本机绝对路径和私人研究记录。标注出处不等于取得再分发许可。

可点击 DOI 出版入口合法取得全文，或选择自己的本地 PDF，在浏览器内对照阅读。文件仅在当前页面内存中解析，不上传；刷新即清除选择。仅阅读位置保存在浏览器 localStorage；无账号、广告、统计脚本或运行时 CDN。GitHub Pages 自身的请求日志由 GitHub 管理。部分中文讲解和代码由 AI 辅助编写，请以论文为准核对。

## 部署与本地查看

GitHub Actions 从 main 分支打包 docs 目录并部署到 Pages，无需另设密钥。构建时下载固定版本的 PDF.js 和 KaTeX，核对 SHA-256 后随站分发；浏览时不依赖第三方 CDN。源码仓库忽略生成的 docs/vendor/。克隆后先运行 `python tools/prepare_vendor.py`，再运行 `python tools/preview.py`，访问 `http://127.0.0.1:8000/`。不要直接以 file:// 打开。

## 文件与许可

docs/content.js 和 docs/terms-expanded.js 保存教学内容；docs/papers.json 仅含公开文献元数据；docs/app.js 提供搜索、关联导航和本地 PDF 阅读。PDF.js 4.10.38 与 KaTeX 0.16.22 本地随包分发，许可证文件保留。自有代码与教学文字暂未授予额外开放再许可；不对第三方论文主张许可。

更正与反馈请使用仓库 Issue；请勿公开论文全文、个人信息、凭据或私密研究记录。

## 为什么需要这些控制方法

首页以多机器人协作的问题为主线，十四章解释原方案的困难、新机制、成立条件、成本与有效性证据，附角色词表和教学比较练习。五十个概念区块与二十篇论文介绍可回到问题主线。

## 看图理解数学

新增十个可离线操作的数学图解：向量、矩阵与秩、导数、积分、反馈、一致性、安全输入区间、误差平方和、Hankel/PE 与标量模态。28 个概念区块、20 个论文区块与 10 处精读段落嵌入预备图，链接到逐步演示；先看图和数字，再选择展开公式。全部为自编教学，不是论文原图或实验。

## 逐篇论文与精读

20 篇来源各有词汇、贡献、前提和研究产出区块；3 篇核心章节精读展开一致性、CBF-QP 与持续激励，附手算例子、反例和自查。实际版本与阅读范围分别说明。公开版不含原文 PDF；本机版另有离线阅读器与启动入口。

## 零基础入门

面向从未接触过控制的读者：4 个部分、12 课，从目标、输入、输出讲起，用调水温、开暖气、定速巡航等生活场景解释反馈、增益、延迟、稳态误差和稳定。附三个离线交互实验（取暖器、定速巡航、三台机器人）、46 个术语表与 3 题起点自测；每课一个自测题和一句本课产出。课程数字来自网页自编的简化模型，不是真实设备实验或论文复现。下载的 `first_control.py` 只用 Python 标准库，可核对课程表格。

## 控制结构地图

从三台机器人过窄门出发，点选十个部分查看各自的失败情境、机制与检验办法。可顺着方法链接读专题和论文区块，核对 DOI、版本与实际阅读范围。比例增益、一致性与 CBF 各有滑条例子，其中 CBF 可以拖到当前条件无可行输入。研究练习用三组虚构对照记录演示怎样在比较完成时间时保留超时，并设计下一轮检查。检查脚本 `tools/check_map.mjs` 核对示例算式、结构、来源和链接。
